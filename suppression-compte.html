Supprimer votre compte WARN

Vous pouvez supprimer votre compte WARN et toutes les données associées à tout moment.

Depuis l'application (immédiat)

  1. Ouvrez WARN et déverrouillez-la.
  2. Allez dans l'onglet Profil.
  3. Touchez Supprimer mon compte, confirmez avec votre code PIN.

Votre compte est effacé immédiatement de notre serveur, ainsi que les données enregistrées sur ce téléphone.

Sans l'application

Si vous n'avez plus accès à l'application, écrivez à gaelzouta@gmail.com avec pour objet « Suppression compte WARN » et le numéro de téléphone du compte. Pour vérifier que la demande vient bien de vous, nous vous enverrons un code par SMS sur ce numéro. La suppression est faite sous 7 jours après vérification.

Ce qui est supprimé

  • Votre numéro de téléphone, votre code PIN (empreinte) et votre profil ;
  • tous vos comptes, opérations, budgets, projets et programme WARN IN ;
  • vos sessions de connexion.

Rien n'est conservé, à l'exception d'une trace anonyme de la suppression (date, sans numéro ni donnée financière). Les copies de sauvegarde techniques sont écrasées automatiquement sous 30 jours maximum.
